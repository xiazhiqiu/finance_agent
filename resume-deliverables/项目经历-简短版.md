## 工小财（中国工商银行客户经理智能提效平台）

**简介**｜面向工行客户经理的内部提效 Agent 系统。基于 pi-agent SDK 构建 Web + pi-gateway + backend 三层架构，以主对话 Agent 为编排中枢，用自然语言唤起即可自动完成客户画像分析、财富方案生成、交付前合规审查与失败自愈重试，替代人工撰写与逐条核对合规的低效环节。

**Key Technologies**｜pi-coding-agent SDK · TypeScript · Node.js · SSE · RBAC · vitest

**核心亮点**
- **Multi-Agent 工作流**｜主对话 Agent 在 ReAct 循环按需调用客户分析、产品/行情查询、方案生成、定向优化等工具；方案生成经 `generate_plan`/`optimize_plan` 工具按需创建无工具、独立 systemPrompt 的叶子 Agent 会话协同，工具调用 + 上下文传递完成分工，自由对话即智能服务。
- **生成-审查自愈闭环**｜叶子 Agent 仅作无工具节点输出方案 JSON，交付前执行风险等级匹配、产品在售、违禁词、风险揭示 4 项确定性审查，失败时以逐条修正指令回灌自愈重试（≤3 次），形成"试错→修正→再验证"收敛闭环。
- **Gen/Det 解耦**｜LLM 只生成方案 JSON，取数与合规审查等确定性逻辑由 TS 编排引擎掌控；人设经 systemPromptOverride 注入与主 Agent 隔离，智能性与可控性统一。
- **记忆沉淀自进化**｜已采纳方案提取洞察沉淀进客户经理个人知识库并优先注入 prompt；基于客户画像余弦相似度做案例检索作 few-shot，方案随使用越贴个人偏好。
- **上下文管控与容错**｜上下文仅注入轻量摘要、完整方案按需取用防膨胀；LLM 坏输出经 `parseJsonWithRepair` 修复重试且反馈脱敏、事故幂等，保障链路稳定。
