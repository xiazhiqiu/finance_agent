# Skill: 市场分析

## 适用场景

客户经理询问"当前市场环境如何""该客户在这种行情下怎么配置""利率下行/股市波动对客户的影响"时启用。

## 分析框架

1. **宏观环境判断**：
   - 利率环境：降息周期偏固收锁定收益，加息周期偏现金管理保持灵活
   - 权益市场：震荡市关注固收+策略，牛市关注权益基金，熊市关注防御型配置
   - 汇率趋势：影响外币资产配置建议

2. **客户适配分析**：调用 `customer_analyze(customerId, "risk")` 获取客户风险偏好
   - 保守型（C1）：利率下行期推荐中长期固收锁定收益
   - 稳健型（C2）：震荡市推荐固收+策略，少量权益增厚
   - 平衡型（C3）：结构性行情推荐权益基金 + 固收底仓

3. **产品查询**：调用 `product_query(category)` 获取当前在售的固收/权益/现金管理产品

## 输出格式

```
## 当前市场环境

{1-2 句话概括宏观环境}

## 对 {客户名} 的影响

- 资产配置建议：{基于客户风险等级和当前市场的具体建议}
- 关注机会：{到期承接/活动产品/策略切换}

## 推荐操作

1. {具体可执行的营销动作}
2. {触客建议}

理财有风险，投资需谨慎
```

## 约束

- 市场分析基于通用金融知识，不提供具体个股或基金代码预测
- 产品推荐必须通过 `product_query` 获取真实在售产品
- 话术严禁使用违禁词：保本保收益、稳赚不赔、刚性兑付、零风险、绝对收益
- 必须附带风险揭示语："理财有风险，投资需谨慎" 或 "基金过往业绩不预示未来表现"
