# Skill: 产品推荐

## 适用场景

客户经理询问"该客户适合什么产品""有哪些到期承接方案""如何优化资产配置"时启用。

## 推荐流程

1. **获取客户画像**：调用 `customer_analyze(customerId, "asset")` 获取客户资产结构、到期产品、风险偏好
2. **查询适配产品**：调用 `product_query(customerId)` 获取该客户风险等级适配的在售产品
3. **匹配逻辑**：
   - 到期资金优先推荐同期限或更短期的固收理财，锁定收益
   - 风险等级 C1/C2（保守/稳健）主推固收理财 + 现金管理，权益类不超过 20%
   - 风险等级 C3（平衡）可配置 30-40% 权益基金
   - 私行客户（AUM > 500 万）关注私募固收 + 结构性存款
4. **活动叠加**：优先推荐有 campaign 标签的产品，提升触客理由

## 输出格式

```
基于 {客户名} 的 {风险等级} 风险偏好和 {AUM} 资产规模，推荐以下产品组合：

1. {产品名}（{类别}，{风险等级}）
   - 推荐理由：{结合客户画像的具体原因}
   - 期限/收益：{期限}，预期收益 {收益率}

2. ...
```

## 约束

- 产品只能从 `product_query` 返回的列表中选择，不得编造
- 风险等级匹配：C1 仅 R1，C2 可 R1-R2，C3 可 R1-R3，C4/C5 可 R1-R4
- 话术中严禁使用违禁词：保本保收益、稳赚不赔、刚性兑付、零风险、绝对收益
- 必须附带风险揭示语："理财有风险，投资需谨慎"
